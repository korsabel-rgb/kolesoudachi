# КОЛЕСО УДАЧИ

Автономная браузерная мини-игра на русском языке. Крути колесо, собирай виртуальные очки и побей свой рекорд. Денежных ставок и реальных выигрышей нет.

## Как запустить

1. Скачай репозиторий: **Code → Download ZIP**, затем распакуй архив. Либо используй `git clone https://github.com/korsabel-rgb/kolesoudachi.git`.
2. Открой `index.html` двойным щелчком в современном Chrome, Edge, Firefox или Safari.
3. Нажми **КРУТИТЬ**.

Ничего устанавливать не нужно. Сервер, интернет, аккаунт и платные сервисы не требуются. На смартфоне открывай HTML через браузер с поддержкой локальных файлов; некоторые файловые просмотрщики не выполняют JavaScript.

## Возможности

- Восемь равных секторов: **10, 25, 50, 100, 200, 500, 1000 очков** и **«Попробуй ещё»**.
- Каждый сектор имеет вероятность **12,5%** в каждом независимом вращении.
- Несколько оборотов с плавным замедлением, указатель и окно результата.
- Синтезированные звуки щелчков и выигрыша, переключатель звука, конфетти.
- Баланс, количество вращений, лучший выигрыш и последние десять результатов.
- Сохранение статистики и настройки звука в `localStorage`.
- Сброс статистики с подтверждением.
- Адаптивный интерфейс, управление с клавиатуры, системная настройка уменьшения движения.

Данные хранятся только в текущем браузере. В приватном режиме, при запрете хранилища или очистке данных они могут исчезнуть. Поведение `localStorage` для `file://` зависит от браузера; перенос или переименование файла может изменить доступ к сохранениям. Если сохранение недоступно, игра показывает предупреждение и продолжает работать в памяти страницы.

## Устройство проекта

- `index.html` — вся игра: HTML, CSS, SVG-колесо, JavaScript и звуки Web Audio.
- `README.md` — запуск, механика и дальнейшее развитие.
- `tests/game.cjs` — автоматические браузерные проверки для разработчиков; для запуска игры не нужен.
- `.gitignore` — исключения для временных файлов.

Список призов `PRIZES` и цвета `COLORS` заданы в начале скрипта. Геометрия, надписи и начисление используют один список призов. Индекс выбирается через `crypto.getRandomValues`: размер диапазона 2³² делится на 8 без остатка. Конечный угол располагается внутри выбранного сектора; фактический выигрыш вычисляется по углу под неподвижным указателем. Повторный запуск блокируется до завершения анимации. Данные имеют ключ `kolesoudachi.v1`, чтобы в дальнейшем можно было добавить миграции.

## Проверка для разработчиков

При наличии Node.js, Playwright и Chromium:

```sh
node tests/game.cjs
```

По умолчанию тест использует `/usr/bin/chromium`; другой исполняемый файл можно указать через `CHROMIUM_PATH`. По умолчанию проверки открывают `index.html` через `file://`, без сервера. Если административная политика браузера запрещает `file://`, запусти `GAME_TEST_HTTP=1 node tests/game.cjs`: тест временно поднимет сервер на локальном адресе и сам остановит его. Проверяют восемь исходов, геометрию указателя, начисление, историю, перезагрузку, блокировку, сброс, звук, обработку недоступного хранилища и мобильные размеры. Автотесты не заменяют прослушивание звука и оценку плавности на реальном устройстве.

## Фактически выполненная проверка

Проверено в Chromium через временный локальный HTTP-сервер: все восемь исходов и конечный угол под стрелкой, начисление очков, история из десяти записей, сохранение после перезагрузки, блокировка повторных нажатий, подтверждение и отмена сброса, настройка звука, правила, обычная анимация, уменьшение движения, запрет и повреждение хранилища. Проверены ширины 320, 375, 390, 640, 768 и 1280 пикселей; снимки компьютерной и мобильной версий просмотрены. Ошибок JavaScript не обнаружено.

Прямой запуск через `file://` в рабочем окружении заблокирован административной политикой Chromium и фактически не проверен. Звук не прослушивался; реальные устройства и другие браузеры не проверялись.

## Как сохранить в GitHub

В каталоге репозитория:

```sh
git add index.html README.md .gitignore tests/game.cjs
git commit -m "Add offline Wheel of Fortune game"
git push origin HEAD
```

Либо используй GitHub Desktop: выбери репозиторий, проверь изменения, нажми **Commit**, затем **Push origin**. Для первого сохранения через веб-интерфейс GitHub можно использовать **Add file → Upload files**.

Загрузка исходников в GitHub сама по себе не включает хостинг. Игра не публиковалась через GitHub Pages или другие сервисы.
